# Ernesto Vizcaíno, Portfolio

A Next.js App Router portfolio managed with [Bun](https://bun.sh/).

## Getting Started

Install dependencies and run the development server:

```bash
bun install
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The application routes live in `app/`, reusable UI lives in `components/`, and
the recovered portfolio content lives in `data/content.js`.

Create a production build with `bun run build` and serve it with `bun run start`.
